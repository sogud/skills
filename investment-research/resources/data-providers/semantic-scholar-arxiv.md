# Semantic Scholar / arXiv Playbook

## Best for

Technical and academic grounding: material science, semiconductor processes, AI infrastructure, biotech, engineering constraints, performance limits, and technical substitution risk.

## Setup Mode

- Built-in or Manual fallback for arXiv.
- API key or Manual fallback for Semantic Scholar.
- Web login / Paid subscription for some publisher pages linked from search results.

## Source Tier

Tier 3: Recognized academic data provider / database.

## What it can support

- Technical feasibility and physical constraints.
- Architecture trends and performance trade-offs.
- Prior art and research direction.
- Substitution risk and competing routes.

## What it cannot support

- Company revenue.
- Customer adoption.
- Commercial readiness by itself.
- Stock-specific conclusions.

## Query / navigation patterns

- Search core technical terms plus synonyms.
- Prefer recent review papers for field overview.
- Use seminal older papers for basic principles.
- Track citations and related work to identify consensus vs frontier claims.
- For commercial claims, pair papers with company filings, standards, patents, or customer announcements.

## Required provenance

Record title, authors, venue/preprint server, publication date, URL/DOI/arXiv ID, key excerpt, and whether the claim is established principle or frontier result.

## Fallbacks

- Google Scholar manual search.
- IEEE/ACM/PubMed/SSRN depending on field.
- Standards body documents for adopted technical rules.
