# OpenCLI Social Sources Playbook

## Best for

Browser or app-mediated access to social, community, or dynamic research pages when normal search/fetch cannot access the data. Useful for logged-in X, Reddit, LinkedIn, Discord, Telegram, Xueqiu, Eastmoney, Substack, and other dynamic sites when an OpenCLI-like adapter exists.

## Setup Mode

- Local install.
- Browser login session.
- Web login.

## Source Tier

Usually Tier 5 for social/forum sources. The tool does not improve the underlying source tier.

## What it can support

- Social narrative capture.
- Logged-in feed visibility.
- Forum posts and community sentiment.
- Dynamic page extraction.
- Screenshots or stable excerpts for audit.

## What it cannot support

- Primary evidence by itself.
- Any claim behind access controls the user is not allowed to access.
- Trading execution or account modification.
- Proof that a social claim is true.

## Query / navigation patterns

- Use only read-only flows.
- Search exact narrative claims and ticker/company terms.
- Capture original URLs, timestamps, and author handles.
- Prefer source-specific official APIs or pages when available.
- Avoid dumping large feeds; summarize and preserve the top evidence points.

## Required provenance

Preserve source platform, URL, author/handle, timestamp, extracted text or screenshot locator, and claim being tested.

## Fallbacks

- Manual browser search.
- Platform-native search.
- Search engines with site filters.
- Direct social APIs when available and authorized.
